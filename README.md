# Covid Simulation
A COVID pandemic simulation. <br>
You may access the simulation at [COVID-SIMULATION](https://www.greenfoot.org/scenarios/35091).
## Features
* Parameterization on population, vaccines, masks, and patient zeros
* The virus evolves so that eventually everyone is infected
* Greenfoot allows slowing down and speeding up the simulation as needed
## Download
1. You may download Greenfoot [here](https://www.greenfoot.org/download).
2. Then download the `gfar` file in the repository.
3. Open the `gfar` file with Greenfoot.
